# Parity matrix: NuvioMobile `core/ui` vs NuvioWeb phone primitives

Research for #46 (part of #44). Primary sources only — no implementation.
No secondary write-ups were used; every row cites the owning source file.

- Mobile root: `/tmp/NuvioMobile/composeApp/src/commonMain/kotlin/com/nuvio/app/core/ui/`
  (plus `features/player/PlayerScreenRuntimeGestureActions.kt` for player gestures)
- Web root: `/Users/akshaynehate/Projects/NuvioWeb/js/ui`
  (`components/`, `theme/`, `navigation/gestureEngine.js`, `screens/`, `css/phone.css`)
- Verdicts: **parity** (equivalent behavior), **diverged** (exists on both, behavior differs),
  **missing** (no web equivalent on the phone path).

## Out of scope / N/A by design

- `NativeTabBridge` (`NativeTabBridge.kt`) — native tab-bar bridge (selected tab, visibility, liquid-glass flag, accent, titles). No web meaning; closest web code is `theme/liquidGlass.js` styling only.
- `PlatformExitApp` / `PlatformImageLoader` / `ResourceLottieCompositionSpec` — platform shims, no UI surface.
- `AppIconPainter`, `ProfileMeshBackground`, `Gradients`, `HsvColor`, `ThemeColorPicker` (settings) — decorative/picker internals with no phone-screen consumer on web found in this pass.
- `DuplicateSafeLazyKeys`, `ScopedDisintegrationTracker`, `DisintegrationRequest`, `AshSwarmRenderer` — supporting machinery for rows above, no direct web surface.
- TV-era web components (`contentCard.js`, `catalogRow.js`, `nuvioDialog.js` TV specs, `sidebarNavigation.js`) are intentionally excluded — phone path only.

## Gist (5 lines)

- Long-press zoom, bottom sheet, shelves, skeletons, dialogs exist on both but diverge in physics: springs/haze/M3 sheets vs CSS transitions/blurs/fixed counts.
- Missing on web phone path: CW action sheet, tracking-list picker, dropdown-as-sheet, floating resume prompt, shared toast/modal/scaffold/inputs, offline card, hero stretch, disintegration, native sheet actuals.
- Hero auto-advance (8s `attachPager`) is web-only — no pager exists in NuvioMobile; native hero behavior is stretch-overscroll, which web lacks.
- Closest to parity: anchor hand-off, watched badge, progress fill, back-handler, safe-area insets, and the player-gesture vocabulary (tuning excepted).
- Suggested build order: shared phone modal/scaffold primitives → CW sheet + pickers → zoom/sheet physics → skeletons → hero stretch → disintegration last.
